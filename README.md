# Expense Tracker using Python

This is a beginner-friendly Python project that helps users record and manage their daily expenses.

The program allows users to add expenses, categorize spending, calculate total expenses, and visualize category-wise spending using a simple bar chart. All expenses are also saved into a text file for future reference.

This project was created to practice Python fundamentals while building something practical and useful.

---

## Features

- Add daily expenses
- Categorize expenses
- Calculate total spending
- Store expenses in a text file
- Display category-wise expense chart
- Simple menu-driven interface

## How to Run the Project

1. Install Python on your system
2. Install matplotlib using:

```bash
pip install matplotlib
```

3. Download or clone this repository
4. Open the project folder
5. Run the following command:

```bash
python main.py
```
